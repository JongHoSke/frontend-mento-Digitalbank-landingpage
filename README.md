# Digitalbank landing page - Frontend Mentor Challenge 

Frontend Mentor의 **Digitalbank Landing Page 챌린지**를 Next.js와 TypeScript로 구현한 반응형 랜딩 페이지입니다.
시멘틱 마크업과 재사용 가능한 컴포넌트 구조를 중심으로 **웹 표준, 접근성, 반응형 UI**에 초점을 맞춰 구현했습니다.

## ✨ Features

- 시멘틱 태그 기반 마크업을 통한 접근성 및 SEO 고려
- Mobile-First 전략을 적용한 반응형 레이아웃
- 햄버거 메뉴 및 모달 UI 구현
- 재사용 가능한 Button, Card 컴포넌트 설계
- TypeScript 기반 Props 타입 관리

## 🛠 Tech Stack

- **Framework**: Next.js 14/15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

## 🧩 Implementation Notes

- header, main, section, article, footer 등 시멘틱 태그를 활용해 구조적인 마크업을 구성했습니다.
- 컴포넌트 분리를 통해 UI 일관성과 유지보수성을 확보했습니다.
- TypeScript interface를 사용해 컴포넌트 Props의 타입 안정성을 강화했습니다.

# Frontend Mentor의 Digitalbank 과제를 Next.js와 TypeScript를 활용해 구현한 반응형 랜딩 페이지입니다.

🛠 Tech Stack

단순한 UI 구현을 넘어 시멘틱 태그를 활용한 웹 표준 준수와 컴포넌트의 재사용성에 초점을 맞추어 개발했습니다.

Framework: Next.js 14/15 (App Router)

Language: TypeScript

Styling: Tailwind CSS

Deployment: Vercel

---

✨ Key Features & Focus

1. 시멘틱 태그 기반의 마크업
   header, main, section, footer, article 등 의미에 맞는 태그를 사용하여 **웹 접근성**과 SEO 성능을 높였습니다.

2. 반응형 디자인
   Mobile-First 방식으로 설계하여 모바일, 태블릿, 데스크탑 등 다양한 해상도에서 최적화된 레이아웃을 제공합니다.

   햄버거 메뉴와 모달 애니메이션을 통해 부드러운 사용자 경험을 구현했습니다.

3. 재사용 가능한 컴포넌트 설계
   Button, Card 등 반복되는 UI를 독립적인 컴포넌트로 분리하여 유지보수성을 높였습니다.

4. TypeScript의 Interface를 활용해 Props의 타입을 엄격하게 관리하여 런타임 에러를 방지했습니다.
